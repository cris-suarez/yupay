# Misión Yupay 🧶

Portal de matemática para secundaria: agendas por grado, fichas, videos, applets de GeoGebra y mini-juegos.

Sitio estático en HTML, CSS y JavaScript puro — no requiere compilación.

- `index.html` — inicio, grados, hoja de ruta y reglas de oro
- `agenda-1.html` … `agenda-5.html` — agendas por grado
- `css/styles.css` — estilos
- `js/main.js` — header, menú, visores, progreso
- `js/juegos.js` — mini-juegos (tendencia central; primos, MCM y MCD)
